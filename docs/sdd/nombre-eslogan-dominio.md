# Nombre, eslogan y dominio

Traza reconstruida el 18 de octubre de 2026. Este archivo no existía antes de la implementación.

Traza: decisión de identidad posterior a las reglas visuales. Índice: [docs/README.md](../README.md).

## Objetivo

Fijar el nombre Aselto, el eslogan «Tus finanzas bajo control» y el dominio web aselto.com en la documentación y en el nombre visible de la aplicación.

## Fuera de alcance

- No renombrar el paquete Dart `app_fiscal` ni el identificador `es.tfm.app_fiscal`.
- No renombrar ni editar los Word DOC-01 a DOC-09.
- No registrar el dominio ni publicar la web.
- No cambiar el nombre del repositorio Git.

## Criterios de aceptación

- El README general, el índice de documentación, las reglas visuales y las instrucciones de agentes citan el nombre, el eslogan y aselto.com.
- Android, iOS y la ventana de Windows muestran Aselto.
- El título de la aplicación Flutter es Aselto.

## Resultado

Integrado en `develop` mediante el pull request #7 (`197437b`, merge `a314664`). El paquete y el identificador siguen siendo `app_fiscal` y `es.tfm.app_fiscal`. El dominio queda anotado para el futuro; el sitio no está publicado.
